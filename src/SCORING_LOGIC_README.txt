Revised scoring model

COMMIT NOW = durable foundation
ENABLE FOR LATER = future capacity
EXPECT TO CHANGE = replaceability
DON'T LOCK IN = optionality

BENDS: at least 3 of the 4 resilience dimensions are represented across the selected capabilities.
STRAINS: only 1 or 2 dimensions are represented; the portfolio is concentrated.
BREAKS: reserved for a future explicit hard-lock decision, such as embedding a current vendor, device, platform, or workflow into the building without a transition path.

Important: COMMIT NOW is not a penalty. A balanced portfolio such as COMMIT NOW + ENABLE FOR LATER + EXPECT TO CHANGE produces BENDS.
